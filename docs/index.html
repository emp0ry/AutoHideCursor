01

Give it a moment.

Choose a timeout of 3, 5, 10, 30 or 60 seconds. The default is 10 seconds. Mouse activity restores the pointer.

02

One-click control.

GETTING STARTED

Download
Launch. Step aside.

Run under your own Windows account. No administrator privileges are needed.

Full installation guide ↗
  1. Get the official executable.

    Download AutoHideCursor.exe from GitHub Releases.

  2. Open the app.

    Its notification-area icon gives you access to all settings.

  3. Choose your interval.

    Right-click for the timeout presets. Left-click toggles auto-hide globally.

  4. Keep it ready.

    Enable Run at Startup if you want it to start with your user session.

To remove: disable Run at Startup, choose Exit, then delete the files. The application restores the pointer when it exits.

A LITTLE MORE CONTEXT

Good to know.

How does the pointer return?+

Mouse movement, button activity and scrolling restore it. Disabling or exiting the utility restores it too.

Can I leave it running?+

Yes. It runs in the notification area, with optional startup and saved preferences.

Is there an installer archive?+

The current official release provides AutoHideCursor.exe. Use the release page for the actual available files.
